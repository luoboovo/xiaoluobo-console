# 闯关模式 · 第一关设计与素材清单

不再使用蔬菜和水果。左边是主角**泽小酱**带领的「山寨 Cos 天团」，右边是第一关守关 Boss **鱼僵军**和他的黑衣帮。

## 一、阵营与兵种

### 左边：泽小酱 + 山寨 Cos 天团（观众操控）

笑点在"廉价 Cos"：衣服有点松、有点皱，造型像但又不太像。名字也全部用谐音或外号。

| 档位 | 兵种（暂定名） | 原型特征 | 定位 | 特殊能力 |
|---|---|---|---|---|
| 主角 | **泽小酱** | 眼镜、蓝色棉服、伸手指人 | 指挥官，一直在场 | 倒下即闯关失败 |
| 弹幕兵（发「1」） | **小丑兵** | 彩虹爆炸头、黄马甲、波点围巾、格子裤 | 人海炮灰 | 扔帽子；阵亡时爆出彩带 |
| 小礼物 | **蛛网侠** | 红蓝紧身衣、网格纹、白眼罩头套 | 远程控制 | 吐网，让敌人减速 |
| 小礼物 | **黑毒侠** | 全黑紧身衣、白色大眼斑 | 肉盾 | 血厚，被打时反咬一口 |
| 中礼物 | **蓝皮侠** | 蓝色条纹紧身衣、尖耳朵、红腰带 | 远程射手 | 射箭，射程最远 |
| 中礼物 | **红肚兜小将** | 双发髻、红坎肩、火焰裤、红缨长枪 | 近战冲锋 | 踩着火轮冲刺，穿透一排敌人 |
| 大礼物 | **紫葫芦娃** | 头顶葫芦、紫色衣裤、绿叶腰带、抱胸 | 控场英雄 | 举葫芦把一片敌人吸进去 |
| 大礼物 | **白毛大佬** | 白色刺猬头、小圆墨镜、黑色立领校服 | 输出英雄 | 结界展开：范围内敌人定身 3 秒 |

### 右边：鱼僵军 + 黑衣帮（系统出兵）

| 兵种 | 特征 | 定位 |
|---|---|---|
| **鱼僵军**（Boss） | 浅棕色两侧推短的发型、黑金巴洛克花纹衬衫、黑 T、脖子上一道纹身线、红披风 | Boss，三阶段（普通、狂暴、大招）；会开口嘲讽，把附近敌人吸引过来打自己 |
| **抱胸亲卫** | 黑色短发、黑色无袖背心、双手抱胸、面无表情 | 精英肉盾，第 2 波起压阵，狂暴阶段再召唤一批 |
| **条纹小弟** | 黑色短发、黑色暗条纹 T 恤 | 普通兵，数量最多 |

### 关卡流程

1. **开场对峙**：泽小酱和鱼僵军的半身像从两边滑进来，中间砸下 VS，各冒一句台词。
2. **第 1～2 波**：条纹小弟从右边涌来，第 2 波起抱胸亲卫压阵。
3. **第 3 波**：鱼僵军登场，顶部出现 Boss 血条。血量低于 50% 狂暴并召唤亲卫，低于 20% 放大招。
4. **结算**：赢了显示鱼僵军跪地、MVP 排行和第二关剪影；输了泽小酱倒地，可以重来。

## 二、生图规矩

1. **画风**：Q 版二头身，大眼睛，粗深色描边，手绘上色，所有角色画风统一。
2. **全身图一律侧面朝右**，包括右边阵营（代码会翻转）。脚落在图片底部正中，四周留少量空白。
3. **一张一张单独出**，分辨率 1024 以上。最好是透明背景 PNG；不能透明就用纯白背景，我来抠图。
4. **画面里不要文字、地面阴影、背景杂物。**
5. **全部画成原创卡通形象**：只保留发型、衣服、道具、动作这些特征，不照着真人的脸画。
6. **不要出现原作的官方标志和名字**：比如蜘蛛标志、正版奥特曼的胸口造型细节。提示词里都写成"自制 Cos 服"的感觉，既保留笑点，也能避免版权投诉。
