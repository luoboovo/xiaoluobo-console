# 蔬菜大战水果 · 第一版素材清单

弹幕阵营对抗玩法：观众发弹幕「1」加入蔬菜军、「2」加入水果军，变成头顶昵称的小兵自动冲锋；礼物召唤兵种、英雄和全屏技能；推倒对方大本营获胜，结算展示 MVP 与排行。

## 一、四条规矩

1. **视角统一**：全部**侧面全身、面朝右**。水果军不单独画朝左的，代码水平翻转，保证两边一致。
2. **画风统一**：Q 版二头身，大眼睛，小手小脚，粗描边，手绘上色。每张图都用同一段风格前缀（见第四节）。
3. **透明背景 PNG**：除背景图外，每张图只画一个角色，不要文字和地面阴影，四周留一点空白。
4. **动画交给代码**：每个兵只出 2 张图，**站立/走路**（代码做一颠一颠地走）和**攻击**。被打、阵亡的效果（闪白、弹飞、碎成果汁）由代码做。

避免画成"豌豆射手站在格子里"那种样子，太像现成的游戏。我们的兵是会跑会冲锋的小人。

## 四、提示词模板

### 统一前缀（每个角色都带上）

```
Asset type: one isolated transparent PNG character sprite for a cute 2D side-view battle game. Style: chibi, 2-head-tall proportion, big shiny eyes, tiny arms and legs, bold dark outline, soft hand-painted shading, bright saturated colors, consistent cartoon game art. Full body, strict side view facing RIGHT, standing on an invisible ground line, centered with small padding. No ground, no shadow, no text, no watermark, no background. Actual transparent alpha background.
```

### 角色描述（接在前缀后面）

- 小萝卜兵：`Subject: a small brave carrot soldier, orange carrot body with green leafy hair, tiny wooden sword, determined happy face. Pose: marching forward.`
- 攻击图只把 Pose 换掉：`Pose: swinging the sword forward energetically.`
- 椰子盾兵：`Subject: a sturdy coconut warrior, brown hairy round shell body, holding a big half-coconut shield in front, calm tough expression.`

其他角色照这个格式写：先写 Subject（长相、武器、表情），再写 Pose。

### 小技巧

先让 AI 出一张"8 个角色站一排"的合影，风格满意后再逐个单独生成，每次都把合影当参考图，画风最稳。
