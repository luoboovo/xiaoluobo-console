# 美式汉堡店 v1.0.3

适用于小萝卜游戏控制台 v2.5.7 及以上版本。已安装 v1.0.0 / v1.0.1 / v1.0.2 汉堡店只需更新主程序，无需重新导入。

在「店铺管理」导入 `artifacts/美式汉堡店-v1.0.3.luobo`，即可创建汉堡店。原有模板、店铺存档和礼物绑定继续沿用。

## 制作方法

1. 把左侧生面包胚拖到烤箱，或点击生面包胚开始烘烤。
2. 把右侧生肉饼拖到煎台，或点击生肉饼开始煎制。
3. 默认各需4秒；烤好后点击烤箱，将面包底放在组装托盘上。也可以从烤箱拖到空位。
4. 将煎好的肉饼从煎台拖到面包底上；也可以先放配料，再放熟肉饼。
5. 自由选加番茄、生菜、芝士、黄芥末酱、番茄酱、沙拉酱和蛋黄酱，所有配料顺序自由。可拖到指定汉堡上；直接点击配料则加到当前选中的汉堡。
6. 把面包上盖拖到汉堡上，或点击「盖上面包」。盖好后不能继续加料。
7. 将汉堡拖给顾客，再将付款拖进钱匣。

烤箱和煎台各容纳4份；托盘有4个默认汉堡位。未熟食材不能取用。烘烤/煎制时长可在控制台设置，保存后下次制作生效。食材未完成或餐品变质时，沿用其他模板的错餐规则。顾客排队、圣水、礼物、评分、查封、补货、帮忙、收钱、清理和场景移动缩放使用现有机制。

## 素材

20项素材均使用内置 imagegen 生图；除背景外均为透明PNG。v1.0.3 新增脏脏汉堡、蟑螂汉堡、可爱蟑螂单张和四帧爬行动画。制作台有原始版与加深台面版，模板使用 `counter-v2.png`。普通汉堡制作过程使用独立食材图片叠放，特殊汉堡盖好后显示对应的完整生图。

`assets/` 包含背景、制作台、煎台、烤箱、生面包胚、面包底、面包上盖、生肉饼、熟肉饼、番茄片、生菜、芝士片、黄芥末酱瓶、酱料层、组装托盘和完整汉堡。既有顾客、厨师手臂、冰柜、垃圾桶、钱匣及礼物素材继续沿用公共模板。

完整提示词保存在 `PROMPTS.md`，生图来源记录在 `sources.json`。运行 `node scripts/create-burger-template.cjs` 可重新生成模板包。

新增素材提示词在 `PROMPTS-v1.0.3.md`，来源在 `sources-v1.0.3.json`。脏餐和蟑螂的详细用法见 `UPDATE-v1.0.3.md`。

三种新酱料瓶均由生图工具独立生成，与黄芥末酱瓶统一瓶型和尺寸；不是界面调色。原图与生成提示词见 `assets/` 和 `PROMPTS-v1.0.3.md`。
