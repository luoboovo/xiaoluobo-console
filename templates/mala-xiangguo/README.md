# 麻辣香锅 v1.0.4

文件：`artifacts/麻辣香锅-v1.0.4.luobo`（约 41.7 MB）。

默认布局改为：碗架和钱匣在左边，放碗托盘在中间，炒锅在右边；芝麻、葱花、香菜摆在桌面后沿，移除悬空配料台。位置与缩放保存于模板布局，不改变其他模板的位置。托盘显示为 440 × 88，碗随托盘等比缩放，仍可同时放四只。

搭配主程序v2.4.5或更新版本，点击左侧碗架即自动摆一个空碗到托盘，从左到右排成一行；快速点击依次摆放，取走后补空位，满位时先出餐或整理。已有模板升级主程序即可生效。

取配料时，光标上的素材使用 `portion_sesame`、`portion_scallions`、`portion_cilantro`，撒下动画也使用散料，不拿走桌面上的料碗。新增芝麻素材由内置 ImageGen 生成并保留透明通道；葱花与香菜复用既有独立散料 PNG。提示词和素材路径见 [PROMPTS-v1.0.4.md](PROMPTS-v1.0.4.md)。

香锅接入原来的 `game.html` 与 `game.js`，共用小人、排队、多个碗、碰撞、出餐、钱匣、打赏、小偷、帮忙、清队、评分、查封、补货、鸡蛋菜叶污染与清理，以及直播画面分层。锅、碗架、菜柜、配料与其他物品仍用原搭建功能拖动、滚轮缩放和保存，恢复默认布局时使用当前模板的位置。

香锅专属操作保留十二格选菜、自动混合翻炒、熟料拖入空碗、三种撒料动画与八种成品图片；每个碗独立保存食材和配料。上层可乐与下层冰红茶可拿取多瓶，沿用原版饮料点单和出餐逻辑。场景没有炒菜和出餐的文字按钮。

试玩：项目根目录运行 `node scripts/preview-stir-fry.cjs`，打开 `http://127.0.0.1:3184/noodle/`。也可在源码版控制台导入模板。安装包未改，原安装版仍不支持新的香锅玩法。

内置 ImageGen 的素材提示词见 [PROMPTS-v1.0.2.md](PROMPTS-v1.0.2.md)。新图集及拆分后的透明 PNG 保存在 `assets/`。

验证：全项目 130 项测试和浏览器拖拽检查通过。浏览器检查覆盖新布局、抓取芝麻与葱花显示独立散料、四个小碗、分别装碗撒料、原版小人、饮料出餐、拖钱入匣、臭料污染、小偷、查封、锅拖动缩放、分层画面和模板切换。安装包及 release 目录未修改；新版玩法需使用当前源码运行时。
